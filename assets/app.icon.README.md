# app.icon (iOS 26+ Liquid Glass icon)

Generated by `python3 scripts/build-app-icon.py` together with `images/icon.png` (flattened: store, splash, iOS < 26), `images/adaptive-icon.png` and `images/adaptive-icon-monochrome.png` (Android) — edit the geometry there, never the SVGs/JSON by hand.
Layer split: group `stripes` (navy, red) floats over group `spade` (stem, gold spade); the green felt is the document `fill`, not a layer (a full-canvas rect in a layer SVG kills the glass and the per-appearance background).
Layer SVGs are plain paths with no transforms/filters; every layer carries an explicit `tinted` gray (spade 1.0, red 0.75, navy 0.55, stem 0.45), because automatic mono from this palette is muddy and the black stem vanishes.
`icon.json` lists groups/layers FRONT-TO-BACK (first = topmost). Validate: `xcrun actool assets/app.icon --compile /tmp/out --app-icon app --platform iphoneos --minimum-deployment-target 16.4 --output-partial-info-plist /tmp/out/p.plist --output-format human-readable-text`. Background: `docs/product/app-store-creative-assets/`.
