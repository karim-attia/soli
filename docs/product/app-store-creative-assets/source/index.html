4 · LIQUID GLASS ICON

Same icon, split into three layers

The current flat PNG gets auto-glassed by iOS 26/27 as one slab. Splitting it into layers in Icon Composer gives the spade depth and lets the system render the Dark, Clear and Tinted appearances from the same file. Geometry below is a recreation of assets/images/icon.png as inline SVG so the layers can be recolored; the real .icon is built by Karim in Icon Composer (macOS 26.4+), then wired as ios.icon in app.json.

Layer 3Stripes (red + navy), top. Specular on, small shadow so they float over the spade.
Layer 2Spade + stem, gold and black. Specular on, slight translucency off (keeps the gold solid).
Layer 1Background, flat felt green #416F57. Icon Composer fills the rounded shape; no rounded corners in the source art.
SourceExport each layer as 1024 px SVG or PNG from the original icon file; the SVG here is a close recreation, not the source art.

5 · OPEN QUESTIONS

Answer by number

  1. MessageRound 3: "Free" removed. Apple treats "free" as a price reference (guideline 2.3.7), and the creative-asset rules ban pricing. "No ads" is a verifiable feature and is allowed (MobilityWare uses it in its subtitle). Now: "Solitaire. No ads. Ever." + "Every deal is winnable." (players say "winnable", not "solvable").
  2. Visual(a) real boards in phone frames on felt (variant A), (b) big celebration frame (variant B), (c) abstract large cards. Recommendation: A now; B's celebration can become the looping video later.
  3. LocalizationEnglish only, or also a German version of the headline? Recommendation: English only, the app is English-only.
  4. IconKeep the current design and only split into layers, or use the occasion for small tweaks (for example a touch more contrast between felt and gold)? Recommendation: same design, no redesign.
  5. Headline typefaceThe mockup uses Bricolage Grotesque with a Fraunces italic subline. Alternative: plain SF/system bold for a more Apple-native look. Recommendation: keep Bricolage, it reads well small and does not look like every other card.
  6. Phones or bare screensThin dark phone frames as shown, or the screenshots as bare rounded rectangles without a bezel? Recommendation: keep the thin frames; they separate the board green from the felt green.
  7. Subline accuracy"Every deal is solvable" is only true by default: solvableGamesOnly can be switched off, and Vegas turns it off. Options: (a) keep it, since it describes the default experience, (b) "Every deal can be won.", (c) "Solvable deals, hints, undo." Recommendation: (a); App Review judges the default experience, and it's true there.
